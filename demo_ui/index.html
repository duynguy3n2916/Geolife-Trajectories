Cách thử

  
Bấm Đặt xe hoặc ô tìm kiếm. Bản đồ tự ghim 🏠 Nhà và 🏢 Công ty trả về từ API; chạm gợi ý hoặc ghim để chọn, hoặc chạm bất kỳ chỗ nào trên bản đồ (kéo ghim để chỉnh). Bấm ô "Vị trí hiện tại" rồi chạm map để đổi điểm đón.

  
Màn chọn điểm đến gọi /api/users/{id}/home-office trên server demo, server này gọi tiếp Home/Office API.

  
Nhãn bên phải "Gợi ý cho bạn" cho biết dữ liệu đến từ API thật hay dữ liệu mẫu. "Xem lời gọi API" hiện đường dẫn, mã trạng thái, thời gian và JSON trả về.

  
Bấm 👤 ở góc trên để đổi người dùng và nguồn dữ liệu. Version model do API tự chọn theo canary (xem nhãn "API · …").
