Các thành phần của hệ thống và cách chúng nối với nhau

Mỗi ô là một vai trò; dòng nhỏ là dịch vụ AWS có thể dùng. Container registry, artifact storage và model registry chỉ dùng lúc deploy và lúc compute khởi động; mỗi request đi User → Ingress → Compute.

Các phương án compute + ingress

4 cách chạy cùng một API: cách hoạt động, ưu và nhược

A. ECS Fargate

User → ALB → ECS Fargate (FastAPI)
ECS kéo image từ ECR, chạy N task trên máy AWS quản lý; ALB chia request cho các task.
  • + Chạy nguyên image, không sửa code; giữ 50 MB
  • + Express tạo sẵn ALB, HTTPS, autoscaling; canary có sẵn
  • − Luôn ≥ 1 task + ALB nên tốn tiền cả lúc rảnh
  • − Không có GPU; shadow phải tự viết
Upload 50 MB · ≈ $58–81/tháng

B. EC2

User → ALB → EC2 chạy Docker
Thuê máy ảo, tự cài Docker và chạy container; ALB tự dựng đứng trước.
  • + Rẻ nhất khi chạy 24/7; toàn quyền với máy
  • + Không sửa code; giữ 50 MB
  • − Tự vá hệ điều hành, tự dựng lại khi máy chết
  • − HTTPS cần domain riêng; canary, blue-green tự dựng
Upload 50 MB · ≈ $49 + ổ EBS/tháng

C. Lambda

User → API Gateway HTTP → Lambda
Mỗi request, Lambda bật một môi trường chạy hàm (FastAPI qua adapter), xong thì tắt dần.
  • + Không ai gọi thì gần như 0 đồng; tự scale
  • + Gần như không phải vận hành; canary bằng alias
  • − Request tối đa 6 MB, chạy tối đa 15 phút, có cold start
  • − Phải thêm adapter, đổi cách upload
Upload 6 MB · < $1/tháng (1.000 request)

D. SageMaker endpoint

User → API Gateway REST → Lambda → SageMaker
Lambda nhận file, gọi invoke_endpoint; SageMaker chạy container ML theo khuôn /ping, /invocations.
  • + Shadow, blue-green, canary có sẵn; gắn Model Registry
  • + Có GPU, Model Monitor cho drift
  • − Sửa container (8080, 2 route); 4 API GET dời sang Lambda
  • − Thêm API Gateway + Lambda; luôn bật
Upload 6–10 MB · ≈ $52/tháng, ≈ $103 kèm shadow

Giá on-demand Singapore tra ngày 10/11. Cả 4 cách đều dùng ECR để chứa image.

Deployment strategy

3 deployment strategy: khác ở chỗ người dùng thật nhận bản mới bao nhiêu, và lúc nào

Hình minh hoạ với ALB làm ingress. ALB không nhân bản request nên shadow trên ECS phải làm trong code; SageMaker có shadow test sẵn. Mức 10% / 50% chỉ là ví dụ.
